<h1 align="center">✋ HandTrackPy</h1>

<p align="center">
  O HandTrackPy é uma aplicação de rastreamento de mãos em tempo real desenvolvida em Python. Utiliza OpenCV e MediaPipe para detectar, rastrear e analisar os movimentos das mãos com alta precisão e baixa latência.
</p>

## <img src="https://github.com/KrishBharadwaj5678/HandTrackPy/raw/main/assets/readme/features.gif" width="35"/> Funcionalidades

| Funcionalidade | Descrição |
|----------------|-----------|
| 🎥 **Rastreamento de Mãos em Tempo Real** | Detecta e rastreia mãos em tempo real utilizando a webcam. |
| ✋ **Suporte a Múltiplas Mãos** | Permite detectar e rastrear várias mãos simultaneamente. |
| ⏳ **Exibição de FPS** | Mostra a taxa de quadros por segundo (FPS) para monitoramento do desempenho. |
| 🖐️ **Detecção de Pontos de Referência** | Detecta os pontos de referência dos dedos e da palma para reconhecimento de gestos. |
| ⚡ **Leve** | Fácil de integrar em outros projetos Python. |
| 🛠️ **Personalizável** | Pode ser adaptado para diversas aplicações baseadas em gestos. |
