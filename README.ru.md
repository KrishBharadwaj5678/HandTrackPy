<h1 align="center">✋ HandTrackPy</h1>

<p align="center">
  HandTrackPy это приложение для отслеживания рук в режиме реального времени, разработанное на Python. Оно использует OpenCV и MediaPipe для обнаружения, отслеживания и анализа движений рук с высокой точностью и минимальной задержкой.
</p>

## <img src="https://github.com/KrishBharadwaj5678/HandTrackPy/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность | Описание |
|-------------|----------|
| 🎥 **Отслеживание рук в реальном времени** | Обнаружение и отслеживание рук через веб-камеру в режиме реального времени. |
| ✋ **Поддержка нескольких рук** | Одновременное обнаружение и отслеживание нескольких рук. |
| ⏳ **Отображение FPS** | Показывает количество кадров в секунду для мониторинга производительности. |
| 🖐️ **Определение ключевых точек** | Обнаруживает ключевые точки пальцев и ладони для распознавания жестов. |
| ⚡ **Лёгкий и быстрый** | Легко интегрируется в другие проекты на Python. |
| 🛠️ **Настраиваемый** | Может быть адаптирован для различных приложений, основанных на распознавании жестов. |

## <img src="https://github.com/KrishBharadwaj5678/HandTrackPy/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонируйте репозиторий

```bash
git clone https://github.com/KrishBharadwaj5678/HandTrackPy.git
```

### 2️⃣ Перейдите в папку проекта

```bash
cd HandTrackPy
```

### 3️⃣ Установите зависимости

```bash
pip install -r requirements.txt
```

### 4️⃣ Запустите приложение

```bash
python app.py
```
