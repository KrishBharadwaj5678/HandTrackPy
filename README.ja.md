<h1 align="center">✋ HandTrackPy</h1>

<p align="center">
  HandTrackPy は、Python で開発されたリアルタイム手検出・追跡アプリケーションです。OpenCV と MediaPipe を使用して、手の動きを高精度かつ低遅延で検出・追跡・解析します。
</p>

  <img src="https://github.com/KrishBharadwaj5678/HandTrackPy/blob/main/HandTracking.png?raw=true" width="500px"/>
</p>

## <img src="https://github.com/KrishBharadwaj5678/HandTrackPy/raw/main/assets/readme/features.gif" width="35"/> 主な機能

| 機能 | 説明 |
|------|------|
| 🎥 **リアルタイム手追跡** | Webカメラ入力を使用してリアルタイムで手を検出・追跡します。 |
| ✋ **複数の手に対応** | 複数の手を同時に検出・追跡できます。 |
| ⏳ **FPS表示** | パフォーマンス確認のためにフレームレート（FPS）を表示します。 |
| 🖐️ **ランドマーク検出** | 指や手のひらのランドマークを検出し、ジェスチャー認識を可能にします。 |
| ⚡ **軽量設計** | 他の Python プロジェクトへ簡単に組み込むことができます。 |
| 🛠️ **カスタマイズ可能** | ジェスチャーベースのさまざまなアプリケーション向けに柔軟に拡張できます。 |

## <img src="https://github.com/KrishBharadwaj5678/HandTrackPy/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/HandTrackPy.git
```

### 2️⃣ プロジェクトフォルダへ移動

```bash
cd HandTrackPy
```

### 3️⃣ 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリケーションを実行

```bash
python app.py
```
